# 抓抓樂 3D 夾娃娃機

用 Three.js 和 cannon.js 做的 3D 夾娃娃機，電腦和手機都能玩，只有一個 HTML 檔。

## 怎麼玩

線上直接玩（電腦、手機都可以）：https://kanoan7643.github.io/claw-machine/

也可以用瀏覽器直接打開 `claw-machine.html`（需要網路載入 3D 引擎）。手機上可以用瀏覽器的「加入主畫面」，之後像 App 一樣開啟。

- **手機**：左下搖桿移動夾子，右下按鈕「開始」投幣、「抓」往下夾。
- **電腦**：方向鍵或 WASD 移動，空白鍵投幣和抓取。
- 拖曳畫面可以轉視角，右上角有「正面／側面」快速切換。

## 功能

- 真實剛體物理：娃娃會堆疊、滾動，夾子吊在纜繩上會擺盪，夾歪的娃娃會滑掉。
- 投幣動畫、瞄準引導線（在設定裡開關，預設關閉）。
- 連續 5 次沒夾到就啟動保夾，下一次必中，並有特效。
- 抓到的娃娃收在背包裡，可以點開 3D 大圖旋轉欣賞。
- 收集紀錄存在瀏覽器的 localStorage。
